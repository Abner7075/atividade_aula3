## 📚 Sobre a Atividade

Nesta atividade, foi escolhido um site considerado **bom** 👍 e outro considerado **tecnicamente ruim** 👎. O objetivo é analisar os dois sites, identificando suas principais **vantagens e desvantagens**.

Após analisar cada site individualmente, será feita uma **comparação entre eles** 🔎, observando aspectos como:

* 🎨 Design e aparência;
* 📋 Organização das informações;
* 🧭 Facilidade de navegação;
* ⚡ Velocidade e desempenho;
* 📱 Responsividade;
* ♿ Acessibilidade;
* 👤 Experiência do usuário;
* 💡 Clareza das informações;
* ⚙️ Estrutura técnica;
* ✅ Pontos positivos e ❌ negativos.

A comparação permitirá entender quais características fazem com que um site ofereça uma experiência melhor ao usuário e quais problemas podem prejudicar sua utilização.
